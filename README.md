# DMIT 机房选择：洛杉矶、香港、东京三地怎么选，先测延迟再挑线路和套餐

搜"DMIT 机房选择"的人，大多卡在同一个地方：官网列表里 LAX、HKG、TYO 三个机房，每个机房下面又分 Pro、EB、T1 三条线，同一个机房里换一档线路，价格能差出一倍多。所以真正难的不是"哪个机房好"——这个问题没有答案，难的是把自己的情况套进去。

下面按选型的实际顺序来：先分清机房和线路是两个独立维度，再看三地的延迟和成本差在哪，然后拿测试 IP 自己验一遍，最后对照当前套餐价格做决定。

## DMIT 机房选择的本质：机房位置 × 网络线路

很多人以为买 DMIT 就是挑城市，其实挑的是两件事的组合。

第一层是机房在哪：洛杉矶（LAX）、香港（HKG）、东京（TYO）。这决定了数据包要跑多少物理距离，也决定了机位和带宽的单位成本。

第二层是这个机房用的是哪条线路。DMIT 把线路分成三档：

- **Pro（Premium）**：中国大陆方向优化最狠的一档，电信走 CN2 GIA、联通走 AS9929、移动走 CMI/CMIN2，去程回程都做优化。
- **EB（Eyeball）**：优化线路里的性价比档，主要靠移动 CMIN2/CMI 和联通 AS9929 撑，同等配置下月流量给得比 Pro 多。
- **T1（Tier 1）**：国际 BGP 线路，不含中国大陆专项优化，价格最低、流量最大、端口最宽。

同一个机房，Pro 和 T1 的差价有时比"香港换洛杉矶"还大。所以正确的问法不是"香港还是洛杉矶"，而是"我需要哪条线路，然后再看哪个机房供得起这条线路"。

差别可以归结成三句话。

香港赢在物理距离。从大陆沿海 ping 过去经常是个位到二三十毫秒，SSH 里敲命令的回显是即时反馈，这种体验洛杉矶给不了。代价是香港的带宽成本高，同配置的 Pro 系列月费是洛杉矶的两三倍，月流量还更少。

洛杉矶赢在单位成本。带宽给得足，10Gbps 端口在 T1 和中高配 Pro 里很常见，同价位能买到的 CPU、内存和流量明显更多。缺点是延迟摆在那里，140ms 起步，晚高峰还有可能往上浮一点。

东京在两个极端中间。延迟通常压在 50ms 以内，对中国北方联通用户有时比香港还舒服一些，价格也比香港温和。它适合那些"不想等洛杉矶那么久、又不想为香港付那么多"的需求。

一个需要说清楚的点：Pro 的价格里有相当一部分买的是晚高峰保障。公开测评里反复提到，Pro 系列以外的高端线路可能因为网络攻击或成本原因调整路由，所以如果 CN2 GIA 是你的硬需求，就别在 EB 和 Pro 之间赌运气，直接上 Pro。

另一个常被忽略的差异是超量后的限速值。T1 用超了还有 100Mbps 到 500Mbps（香港和东京的 WEE 档是 50Mbps），Pro 和 EB 用超了只有 4Mbps 到 10Mbps。前者还能顶着跑轻量业务，后者基本就是"能连上"的程度。月流量估算偏紧的人，T1 的容错空间明显更大。

## 下单前先自己测：Looking Glass 和测试 IP 怎么用

DMIT 提供了官方 Looking Glass，覆盖三个机房的各条线路，做 Ping、Traceroute、MTR 都行。用它做一次十分钟的体检，比看十篇测评有用。

1. 先在自己电脑上 ping 对应机房的测试 IP，记录延迟和丢包率。洛杉矶电信 150–170ms 属于正常区间，香港通常 10–30ms；丢包 0% 是理想状态，超过 5% 就要重新考虑。
2. 再打开 [https://lg.dmit.sh/](https://lg.dmit.sh/)，选对应节点跑 Traceroute，看去程走了哪些骨干。是不是 CN2 GIA、有没有绕路，路由图里看得很清楚。
3. 跑一次 MTR，定位是哪一跳在丢包。如果丢包集中在国际出口，那是本地网络问题，换机房也解决不了。
4. 如果你是电信用户却打算买 T1，务必先测。T1 没有中国大陆优化，电信走 T1 出现"延迟比美国还高"的情况并不罕见。

## 按场景直接给结论

**面向中国大陆用户建站（WordPress、企业站）**：洛杉矶 Pro 或 EB。同价位下配置和流量都比香港宽裕，CN2 GIA 回程能扛住晚高峰。个人站选 Pro TINY 或 Pocket 就够，2GB 内存跑优化过的 WordPress 不吃力。

**远程开发、SSH 重度使用、需要实时反馈**：香港 Pro。延迟是这里唯一的硬指标，其他地方补不回来。

**主要用户是移动宽带**：洛杉矶 EB 或香港对应线路。移动走 CMIN2/CMI，实际体感往往不输高你半档的线路，价格却低一截。

**大流量中转、国际业务、预算优先**：T1 系列。$36.9/年 的 WEE 档是三家机房里最低的入场价，流量用超了还有 50–500Mbps 顶着跑。但请记住 T1 不含中国大陆优化，不要拿它当直连线路用。

**需要 DDoS 防护**：洛杉矶有 Premium Secure（sPro）产品线，走 CFMT 高防线路，三网回程仍是 CN2 GIA，公开报价以 $71.99/季 档为起点。

## 下单前容易忽略的几件事

**流量按出入方向取大值计算。** 不是双向相加，是取上行和下行里更大的那个。做单向大流量业务的人不必按双倍估算，但要清楚规则。

**超量限速不等于断网。** 所有常规套餐流量用完后都是降速不限量，只是降到多少差别很大：T1 有 50–500Mbps，Pro/EB 只有 4–10Mbps。月末经常顶格的业务，选 T1 更安全。

**付款周期影响单价比。** 年付普遍比月付便宜，部分套餐的年付或季付折扣不需要优惠码，直接体现在价格上。DMIT 也会不定期放出按机房、线路、周期区分的循环折扣码，形式通常是机房缩写加折扣比例加付款周期，结算页里填入后点验证即可确认是否可用。不要预设某个码一定有效。

**IP 更换有规则。** DMIT 支持在后台自助更换 IP，不同机房和产品线的审核方式不一样，部分线路需要人工处理。具体是否收费、多久能换一次，写在服务条款的 IP Replacement Policy 章节里，买之前值得花两分钟看一眼。

**特价套餐的服务条款和常规套餐不同。** 比如 WEE 这类特价档不参与流量自助重置。DMIT 上线了按比例付费重置流量的功能，可以在控制面板里选择重置 40% 到 100% 的额度，但覆盖范围不含 WEE 及其他特价产品。

## 常见问题

### 香港和洛杉矶到底选哪个？

看延迟敏不敏感，以及预算。延迟敏感就香港，但要做好月流量少、超量限速低的心理准备。预算优先、业务能忍受 150ms 左右延迟，洛杉矶更划算。

### 电信用户应该选哪条线路？

Pro。CN2 GIA 是 DMIT 优化线路里对中国电信最明确的一档。EB 主要靠 9929 和 CMIN2，T1 完全没有大陆优化，电信走 T1 出现绕路和高丢包的概率不低。

### DMIT 还有圣何塞机房吗？

公开信息显示圣何塞（SJC）地区已停止售卖，目前实际在售的是洛杉矶、香港、东京三地。

### 套餐缺货了怎么办？

DMIT 的库存波动比较频繁，同一机房不同平台（AS3、AN4、AN5）会交替补货。看到合适配置有货时通常建议直接下单，等下一轮补货的时间和价格都不确定。

### 同一机房为什么价格差这么多？

因为硬件平台不同。以洛杉矶 T1 为例，AS3 平台（AMD EPYC 7003）的入门档是 $6.9/月，AN5 平台（AMD EPYC 9005）的同级产品从 $14.9/月起。CPU 代差带来的性能差距在跑分里能看出来，值不值这个差价取决于你的负载类型。

最后提醒一句：上面所有价格取自公开渠道的最近汇总，DMIT 同一机房并行存在多个硬件平台，同档位报价并不完全一致，库存和价格也可能随时调整。正规做法是拿测试 IP 验完网络之后，在结算页确认最终数字。
